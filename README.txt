FIFA Wetten App – Startanleitung:

1. Installiere Python 3.x von python.org (falls noch nicht vorhanden)
2. Öffne PowerShell oder CMD im Projektordner
3. Installiere benötigte Pakete:
   pip install -r requirements.txt

4. Starte die App:
   4.1 Führe aus:
       python create_db.py
   4.2 Dann:
       streamlit run login_router.py

ODER:
- Doppelklicke auf run_app.bat (falls vorhanden)
